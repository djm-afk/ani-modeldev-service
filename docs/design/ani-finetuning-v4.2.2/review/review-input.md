## 两轮讨论

1. 前轮审核R1：登记意图不等于所有具体写操作在途；逐副作用派发与Stop/deadline共同仲裁，RPC/I/O事务外，原业务key保持。测试补入原FT21/FT25。
2. 前轮审核R2：候选经真实BFF的隔离绑定、测试身份与回退操作需要有据可查；它只是联调操作说明，不是新发布平台。
3. 前轮审核R3：A/B完整组合与省略默认的交互明确写成黄金向量；不能自动改另一个参数，不能独立枚举组合全放行。
4. 用户随后明确“现在需要先完成微调的主流程，真实bff验收可以放到后面”。本轮按该优先级改写R2及各任务/验收依赖：合同先定，测试驱动只替代上游来件，真实后端执行和产物先完成；BFF/前端后接仍为最终范围。

本摘要不是新执行授权或新代码审计。仍保留Model分期、GPU独立准备、本机只编辑/Git、Fedora构建验证、172.16.101.10～12集群联合验收的既定边界。
